# Практическая работа 10 — анализ продаж

## Краткий отчёт

Программа анализирует шесть продаж и применяет скидку к первой продаже ноутбука.

## Выполнение по заданию

### 1. Данные

Созданы структура `Sale` и срез продаж из условия. Выводятся все записи и сумма каждой продажи.

### 2. Расчёты

Отдельные функции рассчитывают выручку, самый продаваемый товар и выручку по категориям. Карта объединяет продажи одинаковых товаров.

### 3. Скидка

Функция меняет цену первой записи через указатель. Процент 10 берётся из массива `[5, 10, 15]`.

### 4. Результат

До скидки: 25 единиц, выручка 1 515 000 тг, средняя сумма записи 252 500 тг. Лидер — мышь, 10 штук. Электроника: 1 305 000 тг, аксессуары: 210 000 тг. После скидки выручка 1 445 000 тг.

## Запуск

```powershell
go run .
```

## Вывод

Срез содержит продажи, карты помогают группировать данные, а указатель меняет цену конкретной записи.
